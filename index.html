Mis proyectos de Frontend Mentor

Una colección de proyectos de Frontend Mentor que he creado para practicar y mejorar mis habilidades en HTML, CSS y JavaScript.

Coding Bootcamp Testimonials Slider

Es un componente de testimonios interactivo. El usuario puede navegar entre diferentes testimonios mediante un slider, y el diseño se adapta al tamaño de la pantalla. El desafío también especifica la navegación mediante mouse, trackpad o teclado.

Lo que practiqué: La propiedad position de CSS, el diseño responsive y la creación de un slider de testimonios.

Tecnologías:

  • HTML
  • JavaScript
  • Tailwind CSS
  • PostCSS
Coding Bootcamp Testimonials Slider

Social Media Dashboard with Theme Switcher

Es un dashboard de redes sociales que presenta información relacionada con diferentes plataformas sociales. Una de sus características principales es el theme switcher, que permite alternar entre el modo claro y el modo oscuro. También trabajé los estados hover de los elementos interactivos y el diseño responsive para dispositivos móviles, tablets y computadoras de escritorio.

Lo que practiqué: Diseño responsive, estados hover y la implementación de un tema claro y un tema oscuro utilizando Tailwind CSS.

Tecnologías:

  • HTML
  • Tailwind CSS
  • JavaScript
  • PostCSS
Social Media Dashboard with Theme Switcher

Intro Section with Dropdown Navigation

Este proyecto es una landing page con navegación desplegable. El elemento más importante del proyecto es el menú de navegación, especialmente su comportamiento en diferentes tamaños de pantalla. Cuenta con versiones para dispositivos móviles y computadoras de escritorio, incluyendo los estados con y sin los menús desplegados.

Lo que practiqué: Diseño responsive, navegación desplegable y manipulación del DOM con JavaScript.

Tecnologías:

  • HTML
  • Tailwind CSS
  • JavaScript
  • PostCSS

Notifications Page

Este proyecto reproduce una interfaz de notificaciones siguiendo el diseño proporcionado por Frontend Mentor. El objetivo principal fue conseguir que el diseño fuera lo más fiel posible al original y que funcionara correctamente en diferentes tamaños de pantalla.

Lo que practiqué: Diseño responsive, Flexbox y adaptación del layout a diferentes tamaños de pantalla.

Tecnologías:

  • Tailwind CSS
  • PostCSS
  • HTML

Results Summary Component

Es un componente de resumen de resultados que muestra el rendimiento de un usuario mediante diferentes categorías, cada una con su puntuación. El proyecto se centra principalmente en reproducir fielmente el diseño proporcionado por Frontend Mentor y construir una interfaz responsive que funcione correctamente en distintos tamaños de pantalla.

Lo que practiqué: Diseño responsive, enfoque Mobile First y construcción de layouts utilizando Tailwind CSS.

Tecnologías:

  • HTML
  • PostCSS
  • Tailwind CSS

News Homepage

Es la página principal de un sitio de noticias con diferentes secciones para presentar artículos y contenido destacado. El proyecto trabaja especialmente la organización de múltiples elementos de contenido y la adaptación del layout entre dispositivos móviles y de escritorio.

Lo que practiqué: HTML semántico, diseño responsive, enfoque Mobile First, Flexbox y estados hover y focus.

Tecnologías:

  • HTML
  • Tailwind CSS
  • PostCSS

Sunnyside Agency Landing Page

Es una landing page para una agencia creativa, diseñada para presentar sus servicios, proyectos y propuesta de valor. El proyecto incluye diferentes secciones de contenido, imágenes y elementos visuales, con un diseño responsive que adapta la estructura de la página a diferentes tamaños de pantalla.

Lo que practiqué: La propiedad position de CSS y el uso del atributo popover de HTML para crear elementos interactivos.

Tecnologías:

  • Tailwind CSS
  • PostCSS
  • HTML
